## 给 token 面板加「WorkBuddy 账号维度」（v1.2.0，SCHEMA_VERSION 1→2）

**起因**：用户问"切换 WorkBuddy 账号后看板能识别吗"。结论是原来完全识别不到——取数固定 `~/.workbuddy`，
转录 JSONL 里没有账号字段，events 表也没有账号列，切号后新旧数据静默混算。

**归属来源**：`workbuddy.db` 的 `sessions.user_id`（本机 4 个账号：befe3a40×61 / 76667167×8 / 5ba9f020×4 / 6840d741×2）。

**实现要点**
- 新增 `accounts`（session_id PK → user_id）与 `account_switches` 两张表；`store.init_schema()` 补了版本推进分支。
  **刻意不给 events 加列**——`init_schema` 没有迁移能力，ALTER 就等于重建库；改用查询时 JOIN。
- `credit.py` 每 30 秒把 sessions 全量（**含 deleted_at 非空**，否则软删会话会永久掉进"未归属"）灌进 accounts；
  digest 只含 (session_id,user_id)，改标题不触发 bump。
- `aggregate._acct_sql(acct)` 三档语义：None=全部 / `__none__`=未归属 / uid=该账号。
  **必须 `COALESCE(session_id,'')`**：裸写 `NOT IN` 遇 NULL 会静默丢行，"未归属"少算而"全部"正确。
- `track_switch()` 放采集线程而非 GET 路径；首次只写基线，连续两拍一致才落记录。
- 前端：顶栏账号 chip + 分段筛选 + `⇄` 时间线浮层 + 饼图"账号"档 + 切号 toast。

**不变量（回归就靠它）**：各账号之和 + 未归属 == 全站总量；筛选后 `sum(by_account) == period.tokens`。
`/api/status` 的 `audit.balanced` 暴露它。实测 4 账号 / 归属 99.0% / 未知会话 29 / balanced True。

**踩到的坑**
- Chrome 在 Windows 上窗口最小 500px，`--window-size=390` 截图其实是"500 布局裁到 390"，
  会误判为移动端溢出。用 CDP `Emulation.setDeviceMetricsOverride` 才准。
- PowerShell 里 `Get-Command python` 指向 Microsoft Store 的 0 字节别名，用它启动面板会静默失败；
  真实解释器是 `~/.workbuddy/binaries/python/versions/3.13.12/python.exe`。
- `tools/launch.py` 拉起的子进程会随控制台包装进程一起被杀；长期运行要用独立进程启动。

**顺手修**：`index.html` 里重复的 `id="sessCap"`（第二个改为 `sessCapList`）。


## 打包上传资料库

- `tools/pack.py` 的 SKIP_DIRS 补了 `.workbuddy`：助手记忆与工作区状态不该跟着发行包走。
- 资料库这个空间**不支持 drive 网盘文件**：`upload_drive_file.py` 报「服务端未创建网盘文件节点」。
- `library_upload` 传 zip 会被当成**静态站点包**解开，entry 推断为 `token-panel/web/index.html`；
  而它依赖本地 `/static/*`，放到 CDN 上必然白屏，导出也会因「下载地址无效」失败。
- 可行路径：zip 走 `attachment.py upload` 挂到节点；页面本体另写一个自包含说明页，
  用 `create_page_transaction → upload_page_artifact → commit` 覆盖 entry。commit 不影响附件。
- 教训：在 bash 里用 `python -c "..."` 写含反引号的中文长文，反引号会被 shell 当命令替换吃掉，
  落到文件里会缺字。改用 Write/Edit 工具直接写盘。
