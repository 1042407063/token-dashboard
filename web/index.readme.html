token-panel

WorkBuddy Token 面板 v1.2.0

一个只在本机运行的 WorkBuddy 用量看板。读取 ~/.workbuddy 下的会话转录， 统计 token 与积分消耗，在浏览器里实时展示。数据不出本机。

纯本地 不上传任何内容 Python 3 26 个文件 · 源码 1.2 MB

这个版本新增了什么

  • 账号维度：识别当前登录的 WorkBuddy 账号（UUID 前 8 位），顶栏常驻展示。
  • 按账号拆分：所有统计可按账号筛选，饼图支持「账号占比」，各账号之和与全站总量严格守恒。
  • 切换时间线：记录每次从哪个账号切到哪个账号，保留 180 天。
  • 未归属透明：无法归属的历史会话单独成桶并给出覆盖率，不并进任何账号。

怎么运行

  1. 确认这台电脑装过 WorkBuddy 并用它聊过天——数据来源就是它的转录。
  2. 解压后双击 start-panel.bat，启动器会检查解释器、数据源与端口。
  3. 浏览器打开 http://127.0.0.1:8770/。首次会全量扫一遍历史转录，约 1～2 秒。

不想用启动器：python server.py --open。自检：python tools/selftest.py。
