# 移植与升级

## 一、这个程序是什么写的

| 层 | 技术 | 说明 |
|---|---|---|
| 后端 | **Python 3.7+，纯标准库** | `http.server` 起服务，`sqlite3` 存索引；**没有任何 pip 依赖**，不需要 `pip install` |
| 前端 | 原生 JS + 本地打包的 ECharts | 无构建步骤、无 npm、无 CDN，`web/vendor/echarts.min.js` 直接引用 |
| 存储 | 单个 SQLite 文件 `data/index.db` | 不需要装数据库服务 |
| 启动 | Windows 批处理 + Python 启动器 | `.bat` 只负责找解释器，界面全在 `tools/launch.py` |

一句话：**拷过去、有 Python、双击就能跑**，不存在"环境配置"这一关。

## 二、移植到另一台电脑

### 步骤

1. **打包**（在现在这台机器上）

   ```powershell
   cd D:\dev\myproj\Token看板
   python tools\pack.py
   ```

   生成 `dist/token-panel-<版本>.zip`，约 0.4 MB。包里**不含 `data/`**——
   那是这台机器的索引和日志，带过去会看到本机的用量，而且首次启动还会覆盖重建。

2. **拷贝**：把 zip 用 U 盘 / 微信文件传输 / 网盘发到目标电脑，解压到任意目录。

3. **确认前置条件**（目标机器）：
   - 装过 **WorkBuddy** 并且用它聊过天 —— 面板的数据来源就是 `~/.workbuddy` 的转录
   - 有 **Python 3.7+**。装过 WorkBuddy 的话它自带一份，启动器会优先用它

4. **启动**：双击 `start-panel.bat`。第一次会全量扫一遍历史转录（几十秒），
   之后都是增量扫描，打开就是秒开。

> 也可以直接拷整个目录（不打包），只要排除 `data/` 即可。

### 启动器会自己找解释器

顺序是：WorkBuddy 自带 → PATH 里的 `python`（跳过微软商店那个 0 字节占位符）→ 常见安装目录。
都找不到才报错，并打印搜索过哪些位置。

## 三、适配性评估

| 场景 | 情况 |
|---|---|
| Windows 10/11 + WorkBuddy | **完全可用**，就是当前形态 |
| Windows 但没有 WorkBuddy | 能启动，但没有数据源，启动器第 2 步会明确提示 |
| macOS / Linux | **服务端能直接跑**（`python server.py --open`），但 `.bat` 启动器和自动启动脚本用不了 |
| 多台电脑同时用 | 各自独立，见下面的提醒 |

平台相关的代码只集中在一处：

- `tools/launch.py`：控制台颜色（ctypes）、单键读取（msvcrt）、停止进程（taskkill）
- 三个 `.bat` 与 `tools/autostart.py`（写启动文件夹）

`server.py` / `aggregate.py` / `store.py` / `indexer.py` / `credit.py` 里**没有任何平台判断**，
换系统时这几块不用动。

## 四、以后怎么升级

改动只会发生在代码里，**数据在 `data/` 目录，升级时不要删它**。

1. 在新版本目录里改好，把 `VERSION` 升上去（现在在项目根目录）
2. `python tools\pack.py` 打出新包
3. 目标电脑上：
   - 用新包里的 `.py` / `web/` / `tools/` **覆盖**旧目录
   - **保留** `data/`（索引）和 `data/notify.json`（微信推送配置）
   - 重启面板即可

索引有 schema 版本号（`config.SCHEMA_VERSION`），结构变了会自动重建，不用手工删库。

## 五、一个必须知道的限制

**两台电脑的数据不会合并。** 面板读的是**本机**的 `~/.workbuddy` 转录，
所以家里那台只看得到家里那台的用量，公司这台的数字不会同步过去。

如果你想要"两台合起来看"，那需要另一套机制（导出汇总文件 + 合并统计），
目前没做——真要做的话，得先决定合并的粒度（按天？按会话？会不会重复计数）。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 启动器说找不到 `~/.workbuddy/projects` | 目标机器没装 WorkBuddy，或没聊过天 |
| 双击后闪一下就没了 | 看 `data/panel.log`；或用 `python server.py --open` 直接跑，能看到报错 |
| 端口 8770 被占 | 启动器会提示，服务自动顺延到 8771–8779 |
| 想看自检结果 | `python tools/selftest.py` |
| 想测性能 | `python tools/bench.py` |
